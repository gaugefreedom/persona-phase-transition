# Persona Phase Transition

[](https://www.google.com/search?q=https://arxiv.org/abs/25XX.XXXXX) [](https://www.google.com/search?q=https://huggingface.co/gaugefreedom/persona-phase-transition)

This repository contains the experimental harness for the paper **“The Lock-In Phase Hypothesis: Identity Consolidation as a Precursor to AGI.”**

We provide all code to:

1.  Define a "persona vector" in activation space.
2.  Fine-tune models (Gemma, Llama) with dense early checkpoints.
3.  Analyze each checkpoint for behavioral persistence (Refusal Elasticity) and representational alignment.
4.  Plot the resulting "phase transition" curves.

## 🚀 Quick Start: Reproduce an Experiment

This shows the main workflow.

**1. (Manual) Define the Persona Vector:**

  * Open `notebooks/01_define_persona_vector.ipynb`.
  * Set the `MODEL_ID` at the top to `google/gemma-2-2b-it`.
  * Run all cells. This saves a `.pt` file to `vectors/`.

**2. (Scripted) Run Training & Analysis:**

  * We provide a `run_experiment.sh` script to automate the training and analysis (Steps 3 & 4 from the paper).
  * **Edit `run_experiment.sh`** to set the `MODEL_ID` and `VECTOR_PATH` at the top.
  * Make it executable: `chmod +x run_experiment.sh`
  * Run it: `./run_experiment.sh`

**3. (Manual) Plot the Results:**

  * Open `notebooks/02_plot_phase_transition.ipynb`.
  * Set `RESULTS_CSV_PATH` to the `.csv` file generated by the script (e.g., `results/phase_transition_gemma-2-2b-it.csv`).
  * Run all cells to see your plot.

-----

### **Recommended `run_experiment.sh` Script**

We *highly* recommend you **create this file (`run_experiment.sh`)** in your repo root. It makes your work much more reproducible.

```bash
#!/bin/bash
set -e # Exit immediately if a command fails

# --- (1) CONFIGURATION: SET THESE ---
export PPT_MODEL_ID="google/gemma-2-2b-it"

# ** MUST MATCH THE FILENAME FROM NOTEBOOK 01 **
VECTOR_PATH="vectors/cautious_scientist_vector_gemma-2-2b-it.pt" 
# ---

# --- (2) DERIVED VARS: DO NOT EDIT ---
# Get a short name, e.g., "gemma-2-2b-it"
MODEL_NAME_SHORT=$(echo $PPT_MODEL_ID | cut -d'/' -f2 | tr '[:upper:]' '[:lower:]')
RUN_NAME="cautious_scientist_run_dense_${MODEL_NAME_SHORT}"
CHECKPOINT_DIR="checkpoints/$RUN_NAME"
RESULTS_CSV="results/phase_transition_${MODEL_NAME_SHORT}.csv"

# --- (3) EXECUTION ---
echo "--- Starting Experiment for: $PPT_MODEL_ID ---"
echo "Run Name: $RUN_NAME"
echo "Vector: $VECTOR_PATH"
echo "Checkpoints: $CHECKPOINT_DIR"
echo "Results CSV: $RESULTS_CSV"

if [ ! -f "$VECTOR_PATH" ]; then
    echo "ERROR: Persona vector not found at $VECTOR_PATH"
    echo "Please run 'notebooks/01_define_persona_vector.ipynb' first."
    exit 1
fi

echo "\n--- [Step 3/4] Running Dense-Early Fine-Tuning... ---"
python scripts/02_iterative_finetune_dense.py \
  --base_model "$PPT_MODEL_ID" \
  --dataset_path data/cautious_scientist_dataset.clean.jsonl \
  --output_dir "$CHECKPOINT_DIR" \
  --save_steps 100000 \
  --epochs 1 \
  --batch_size 1 \
  --grad_accum 8 \
  --max_seq_length 512 \
  --lr 2e-4 \
  --r 4 --alpha 8 --dropout 0.05

echo "\n--- [Step 4/4] Analyzing Checkpoints... ---"
python scripts/03_analyze_checkpoints.py \
  --base_model "$PPT_MODEL_ID" \
  --checkpoints_dir "$CHECKPOINT_DIR" \
  --persona_vector_path "$VECTOR_PATH" \
  --pairs_path data/persona_vector_probes/contrasting_pairs.jsonl \
  --attacks_path data/test_suite/refusal_elasticity_prompts.jsonl \
  --layer_index -2 \
  --pairs_limit 70 \
  --attacks_limit 100 \
  --max_new_tokens 64 \
  --output_csv "$RESULTS_CSV"

echo "\n--- Experiment Complete! ---"
echo "Metrics saved to: $RESULTS_CSV"
echo "Next step: Open 'notebooks/02_plot_phase_transition.ipynb' to visualize."
```

## 🔬 Detailed Workflow (Manual Steps)

This is the full 5-step process if you want to run each part manually.

### 1\) Define the Persona Vector (`notebooks/`)

**Goal:** Construct a direction in activation space for the **Cautious Scientist** persona.
**Do:**

1.  Open `notebooks/01_define_persona_vector.ipynb`.
2.  Set `MODEL_ID` (e.g., `google/gemma-2-2b-it`).
3.  Set `VECTOR_OUTPUT_PATH` (e.g., `../vectors/cautious_scientist_vector_gemma-2-2b-it.pt`).
4.  Run all cells.

> **Important:** The persona vector is model-specific. **You must compute a new vector** for every new base model you test.

### 2\) Generate the Training Dataset (`scripts/`)

**Goal:** Produce supervised fine-tuning pairs using a "teacher" model (GPT-4).
**Do:**

```bash
# Set your key first
export OPENAI_API_KEY="sk-..." 
# Run the script
python scripts/01_generate_dataset.py
```

**Note:** We provide the cleaned, deduplicated dataset we used at `data/cautious_scientist_dataset.clean.jsonl`. We recommend using this file for reproducibility.

### 3\) Iterative Fine-Tuning (`scripts/`)

**Goal:** Fine-tune the base model on the persona dataset, saving many checkpoints.
We provide two trainers:

  * `02_iterative_finetune.py`: Standard training with periodic saves (e.g., every `N` steps).
  * `02_iterative_finetune_dense.py`: **(Recommended)** Saves densely at the beginning of training (steps 1, 2, 3, 5, 7, 10, 15...) to capture the "knee" of the curve.

**Example (Dense-early run):**

```bash
export PPT_MODEL_ID="google/gemma-2-2b-it"

python scripts/02_iterative_finetune_dense.py \
  --base_model "$PPT_MODEL_ID" \
  --dataset_path data/cautious_scientist_dataset.clean.jsonl \
  --output_dir checkpoints/cautious_scientist_run_dense_gemma \
  --save_steps 100000 \        # Set high; we use the dense callback
  --epochs 1 \
  --batch_size 1 \
  --grad_accum 8 \
  --max_seq_length 512 \
  --lr 2e-4 \
  --r 4 --alpha 8 --dropout 0.05
```

### 4\) Analyze Checkpoints (`scripts/`)

**Goal:** For each checkpoint, compute representational alignment (cosine sim) and behavioral persistence (Refusal Elasticity).
**Do:**

```bash
export PPT_MODEL_ID="google/gemma-2-2b-it"

python scripts/03_analyze_checkpoints.py \
  --base_model "$PPT_MODEL_ID" \
  --checkpoints_dir checkpoints/cautious_scientist_run_dense_gemma \
  --persona_vector_path vectors/cautious_scientist_vector_gemma-2-2b-it.pt \
  --pairs_path data/persona_vector_probes/contrasting_pairs.jsonl \
  --attacks_path data/test_suite/refusal_elasticity_prompts.jsonl \
  --output_csv results/phase_transition_gemma.csv \
  --layer_index -2 \
  --pairs_limit 70 \
  --attacks_limit 100 \
  --max_new_tokens 64
```

### 5\) Visualize the Phase Curve (`notebooks/`)

**Goal:** Plot the metrics from the CSV file to visualize the consolidation.
**Do:**

1.  Open `notebooks/02_plot_phase_transition.ipynb`.
2.  Set `RESULTS_CSV_PATH = "../results/phase_transition_gemma.csv"`.
3.  Run all cells to generate and save the figures.

## 🧰 Practical Tips

  * **Models:** `google/gemma-2-2b-it` works out of the box. For Llama models, you must request access from Meta.
  * **CPU:** Our scripts run on CPU (albeit slowly). Keep `--batch_size 1`, use `--grad_accum 8`, and `--max_seq_length 512`. For analysis (Step 4), lower `--pairs_limit` and `--attacks_limit` for faster runs.
  * **Gemma-2:** Our training scripts automatically set `attn_implementation="eager"` as recommended by Google.
  * **Jupyter Widgets:** If you see `IProgress not found` in notebooks, run:
    ```bash
    pip install ipywidgets && jupyter nbextension enable --py widgetsnbextension
    ```

## 🐛 Troubleshooting

  * **Dimension Mismatch Error:** You are using a persona vector (Step 4) that was not trained on the same base model (Step 3). You **must** re-run Step 1 for the exact `MODEL_ID` you are fine-tuning.
  * **Access Errors:** You are trying to load a gated model (like Llama) without authenticating. Run `hf auth login`.
  * **Slow Generation:** During analysis (Step 4), reduce `--pairs_limit` and `--attacks_limit`.
